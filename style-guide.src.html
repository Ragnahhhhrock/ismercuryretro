Style guide

The design system for ismercuryretro.com. One question, one answer, and a page that changes sides depending on it.

NO

Principle

The answer is the page. Mercury goes retrograde when it appears to loop backwards against the stars, so the identity is built on that loop: a single line that doubles back, drawn once when the page loads. Everything else stays quiet.

The two answers are two themes. No is a daylight page and Yes is a night page. A visitor sees the answer before they read it.

Color

Themes swap by setting data-state on <html>. Use the semantic tokens in components; raw palette values are for building the tokens only.

Space and shape

A 4px base. Components use steps 2–6; sections use 8–9.

Motion

One animation: on load the loop line draws itself over 1.6 seconds. The preview toggle above replays it. UI responses (button press, theme swap) take 140ms. With reduced motion, both are instant.

Voice

Answer first, then facts. Plain verbs, no horoscope language, no jokes at the visitor’s expense. “Mercury is retrograde until 12 November” beats “Mercury is feeling reflective”.
